# 显示器刷新率和方向调整工具

## 项目简介
本工具基于 Rust 和 Windows API，可用于修改 Windows 显示器的设置。

## 功能特点
- **调整刷新率**：可手动指定刷新率，若未指定，则不修改。
- **调整屏幕方向**：支持 0、90、180、270 度旋转。
- **调整屏幕分辨率大小**：支持屏幕分辨率的设置。
- **调整显示模式**：支持仅主显示器/仅副显示器/复制模式/扩展模式。
- **支持多显示器**：可选择要调整的显示器。

## 安装方法
### 1. 安装 Rust
确保已安装 Rust 运行环境，可参考官方文档：[Rust 官网](https://www.rust-lang.org/zh-CN/tools/install)

### 2. 克隆项目并编译
```sh
# 克隆仓库
git clone https://github.com/Colzry/DisplaySetting.git
cd DisplaySetting

# 编译项目
cargo build --release
```

## 使用方法
编译后，在 `target/release/` 目录下找到可执行文件 `DisplaySetting.exe`。

```sh
# 查看帮助信息
./DisplaySetting.exe --help

# 设置刷新率为 120Hz，旋转 90 度，目标显示器为 显示器1
./DisplaySetting.exe -r 120 -o 90 -d 1

# 仅更改刷新率
./DisplaySetting.exe -r 144

# 自适应显示器支持的最高刷新率
./DisplaySetting.exe -r 0

# 仅更改屏幕方向
./DisplaySetting.exe -o 90

# 设置扩展模式
./DisplaySetting.exe -m 4
```

## 参数说明
| 参数 | 说明                                            |
|------|-----------------------------------------------|
| `-r, --refresh-rate` | 设定刷新率（单位 Hz），不指定则不修改，0自动适应最高刷新率               |
| `-o, --orientation` | 设定屏幕方向（可选值：0-横向/90-纵向/180-横向翻转/270-纵向翻转） 默认 0 |
| `-d, --display` | 目标显示器 (1-显示器1/2-显示器2)，默认 1                    |
| `-w, --width` | 设定目标分辨率宽度，需与 `--height` 一起使用，不指定则不修改          |
| `-h, --height` | 设定目标分辨率高度，需与 `--width` 一起使用，不指定则不修改           |
| `-m, --mode` | 设置显示模式 (可选值：1-仅主屏/2-仅副屏/3-复制/4-扩展)，不指定则不修改    |

## 常见问题
### 1. **修改后部分设置无效？**
Windows 可能不会立即应用所有更改，尝试手动重新应用显示设置：
- 进入 **显示设置** → **高级显示设置**，手动调整刷新率或旋转角度。
- 可能需要管理员权限运行本工具。

### 2. **无法找到目标显示器？**
- 确保显示器已正确连接。
- 使用 `-d` 参数指定正确的显示器索引。

### 3. **刷新率修改无效？**
- 部分显示器可能不支持特定刷新率，请尝试不同的值。
- 显示器需要支持该刷新率，并且显卡驱动需正确安装。

## 注意事项
1. 显示器数量要求：
- 显示模式设置需要至少2个显示器

2. 分辨率设置：
- 在复制模式下设置分辨率会影响所有显示器
- 在扩展模式下可以单独设置每个显示器的分辨率

3. 兼容性：
- 某些旧显卡可能不支持所有显示模式
- 如果设置失败，请检查显卡驱动是否为最新版本
